Ouvre 6 boosters de Wilds Unknown et construis ton deck de 40+ cartes selon les règles officielles du format Sealed Lorcana.

  • 6 boosters · 12 cartes chacun · 72 cartes au total
  • Composition booster : 6 Common (1 par couleur) + 3 Uncommon + 2 Rare+ garantis + 1 Foil independant
  • Pool complete : 242 cartes (204 main + 18 Epic + 18 Enchanted + 2 Iconic)
  • Sur 6 packs (Sealed) : ~1.6 Legendary moyen, ~3 Super Rare, ~10% chance d'Enchanted
  • Deck minimum 40 cartes · pas de limite d'encres · pas de limite de copies
Pool complete : 242 cartes La pool inclut la totalite du set Wilds Unknown : 204 cartes principales (Common a Legendary) + 18 Epic + 18 Enchanted + 2 Iconic. Toutes les images officielles sont chargees. Les ratios de pull sont calibres sur les ouvertures reelles du chapitre 12 : ~2 Epic et ~6-7 Legendary par display, ~1-2 Enchanted par case (96 packs).

Mode multijoueur (optionnel)

A 2-4 joueurs, partagez un meme code de display pour ouvrir les memes boosters (chacun ses 6 dans la display). Idem pour une pre-release a domicile.

Mode multijoueur

Solo : laisse le code vide, clique Ouvrir. Tu obtiens 6 boosters aleatoires.

A plusieurs : un joueur (l'organisateur) ouvre une session SANS code, choisit le nombre de joueurs, et obtient un code apres ouverture. Il partage ce code aux autres.

Les autres joueurs : entrez le code recu, choisissez votre numero de joueur (different de chacun), et le meme nombre total de joueurs. Vous obtenez vos 6 boosters de la meme display.

Chaque joueur reçoit des boosters DIFFERENTS issus d'une display commune de 24 boosters. Comme une vraie pre-release.
